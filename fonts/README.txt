Fonts of tas3d.uz

helvtas-400.woff, helvtas-500.woff, helvtas-700.woff
  Subsets of Helvetica (Latin letters, digits, punctuation; no Cyrillic).
  Helvetica is a commercial typeface (Monotype/Linotype): the site needs a web
  licence for it. The CFF table of the 500 and 700 files was rebuilt with
  fontTools so that Chrome accepts them.

cyr-400.woff, cyr-700.woff
  Cyrillic subset (U+0400–04FF, U+2116) of FreeSans and FreeSans Bold from
  GNU FreeFont, version 0412.4271. Used only for Russian letters on devices
  without Helvetica (Windows, Android). On Mac and iPhone the system Helvetica
  is used instead (local() in the CSS).
